# UI_RULES.md

## 레이아웃 기준

- 기준 해상도: `360 x 640` 시작, 실제 디바이스 비율 대응
- 터치 타깃 최소 크기: `48dp`
- 상단 고정 정보: 피로도, 골드, 프리미엄 재화
- 하단 고정 정보: 이동/액션/메뉴

## 실무형 품질 기준

- 버튼 종류는 역할별 3종 이하로 제한
- 한 화면에서 핵심 CTA는 1개, 보조 CTA는 2개 이하
- 팝업 닫기와 결제/광고 CTA는 충분히 분리
- 배경 장식이 정보 가독성을 침범하면 제거

## 과금/광고 UX 가드레일

- 피로도 부족 팝업에 `무료 회복 경로`를 먼저 노출
- 보상형 광고는 보상량과 수령 실패 정책을 명시
- 전면 광고는 전투 도중 노출 금지
- 배너는 HUD 필수 정보와 겹치지 않게 격리

## 초보자 관점 점검 항목

- 처음 보는 사용자가 `다음 행동`을 3초 내 파악 가능한가
- 잠금 요소의 해금 조건이 읽히는가
- 광고/IAP CTA를 `강제 결제 유도`로 오해하지 않는가
- 자동전투와 수동전투 전환이 헷갈리지 않는가
