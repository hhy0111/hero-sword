## 1. 뽑기 확률과 캐릭터 노출 문제

### 현재 확인된 구조

- 일반 뽑기 확률:
  - 5성: 5%
  - 4성: 20%
  - 3성: 75%
- 10회 뽑기:
  - 최소 4성 이상 1개 보장.
  - 앞의 9개가 모두 3성이면 마지막 보장 슬롯에서 5성이 20% 확률로 나올 수 있다.
- 현재 구조에서 10회 뽑기 1번에 5성이 1개 이상 포함될 확률은 약 41% 수준이다.

### 문제

- 캐릭터 수집형 RPG 기준으로 5성 노출이 빠르다.
- 전체 캐릭터 풀이 아직 크지 않기 때문에, 몇 번의 10회 뽑기만으로 주요 캐릭터가 대부분 노출될 위험이 있다.
- 사용자의 방향성은 "끝까지 얻지 못하는 캐릭터도 있어야 한다"에 가깝다.
- 현재 픽업 카드가 5성과 4성을 같은 줄에서 비슷하게 보여주기 때문에, 미카엘라 같은 4성 캐릭터도 최상위 보상처럼 오해될 수 있다.

### 추가 작업 방향

- 5성 기본 확률을 낮춘다.
- 검토 기준안:
  - 5성 기본 확률: 1%~2%
  - 4성 기본 확률: 8%~12%
  - 10회 보장은 4성 이상 보장으로 유지하되, 보장 슬롯에서 5성 확률을 과하게 올리지 않는다.
  - 천장 시스템은 도입하더라도 UI에서 명확히 설명할 수 있을 때만 적용한다.
- 일부 캐릭터는 기본 뽑기 풀에서 제외하고 아래 조건으로 해금한다.
  - 스토리 진행
  - 대륙 클리어
  - 궁궐 퀘스트
  - 한정 배너
  - 조각/이벤트 시스템
- 픽업 카드에는 반드시 등급과 의미를 표시한다.
  - `5성 픽업`
  - `4성 픽업`
  - `무기 픽업`
- 미카엘라는 5성이 아니라 4성 픽업 힐러로 명확히 보여야 한다.

## 2. 중복 획득과 초월 UX

### 현재 확인된 구조

- 중복 캐릭터는 사본 수로 저장된다.
- 초월 수치는 사본 수에서 계산된다.
  - 1장: 초월 0
  - 2장: 초월 1
  - 3장: 초월 2
  - 최대 6장: 초월 5
- 7장째부터는 영웅석으로 전환된다.
  - 3성: 영웅석 +6
  - 4성: 영웅석 +16
  - 5성: 영웅석 +40
- 현재는 3성 2장을 합쳐 4성으로 만드는 조합/승급 시스템은 없다.

### 문제

- 플레이어가 뽑기 직후 "초월이 됐는지", "얼마나 강해졌는지" 알기 어렵다.
- 중복 획득이 보상처럼 느껴지지 않고 실패처럼 느껴질 수 있다.
- 파티 화면에 가야 초월 수치를 확인할 수 있어, 뽑기 결과와 성장 효과가 연결되지 않는다.

### 추가 작업 방향

- 뽑기 결과 카드에서 상태를 명확히 표시한다.
  - 신규 캐릭터: `NEW 캐릭터 획득`
  - 중복 캐릭터: `중복 획득 -> 초월 +1`
  - 예시: `브람 중복 획득 | 초월 0 -> 1 | 전투력 +80`
  - 초월 최대 이후: `초월 최대 | 영웅석 +6 전환`
- 10회 뽑기 결과 요약을 추가한다.
  - `신규 1명`
  - `초월 2회`
  - `영웅석 +12`
  - `무기 사본 +3`
- 파티/캐릭터 상세 화면에도 아래 정보를 항상 표시한다.
  - 현재 초월
  - 현재 사본 수
  - 다음 초월까지 필요한 사본
  - 초월로 오른 전투력
- 향후 3성 조합/승급 시스템을 넣을 경우, 현재 초월 시스템과 별도 규칙으로 문서화한다.

## 3. 전투 결과 화면 보완

### 현재 확인된 문제

- 클리어 시간과 입힌 피해가 전투 결과 주요 정보처럼 보인다.
- 획득 경험치가 단순 텍스트로만 표시되어 성장 보상이 약하게 느껴진다.
- `클리어했습니다. 다음 행동을 선택하세요.` 문구가 하단에서 별도 블럭을 크게 차지한다.

### 추가 작업 방향

- 기본 결과 패널에서 제거한다.
  - 클리어 시간
  - 입힌 피해
- 획득 경험치 영역을 넓힌다.
- 캐릭터별 경험치 표시를 강화한다.
  - 캐릭터 사진
  - 이름
  - 현재 레벨
  - 이번 전투에서 얻은 경험치
  - 다음 레벨까지 남은 진행도 프로그래스바
- 프로그래스바는 이번에 오른 양이 보이도록 한다.
  - 전투 전 진행도
  - 이번 획득량
  - 전투 후 진행도
- 레벨업이 발생하면 `LEVEL UP` 또는 `레벨 상승`을 강조한다.
- 하단 안내 문구는 별도 큰 블럭으로 두지 않는다.
  - 버튼 영역 테두리 또는 버튼 위 작은 푸터 문구로 이동한다.
- 결과 화면의 중심은 "클리어했다"가 아니라 "캐릭터가 성장했다"가 되어야 한다.

## 4. 스테이지 선택과 루트 진행 보완

### 현재 확인된 문제

- 루트 진행 리스트에서 기본 아이콘처럼 보이는 마커가 남아 있다.
- 리스트가 아직 게임 UI라기보다 임시 목록처럼 보인다.
- 하단 스테이지 선택 텍스트가 배경 영역을 벗어난다.
- `스크롤 1/20` 문구가 플레이어에게 어떤 의미인지 불명확하다.
- 마우스 휠로 스크롤이 움직인다.

### 추가 작업 방향

- 루트 진행 리스트의 기본 아이콘을 교체한다.
  - 진입 가능: 빛나는 루트 노드 또는 녹색 인장
  - 클리어 완료: 금색 체크/완료 인장
  - 잠김: 어두운 잠금 인장
  - 현재 선택: 테두리와 발광 강조
- 기존 에셋에 적합한 아이콘이 있는지 점검한다.
- 없으면 추가 이미지 프롬프트를 만든다.
  - 루트 상태 아이콘
  - 스테이지 노드 마커
  - 잠김/완료/진입가능 상태별 버튼 장식
- 하단 텍스트 영역을 정리한다.
  - 모든 텍스트가 배경 안에 들어오도록 줄임.
  - 긴 문구는 축약하거나 2줄 기준으로 맞춤.
  - 버튼/테두리/화면 하단과 겹치지 않도록 안전 영역 적용.
- `스크롤 1/20`은 기능적 의미가 없으면 삭제한다.
- 모바일 출시 기준으로 마우스 휠 스크롤을 제거한다.
- 조작은 터치 중심으로 통일한다.
  - 리스트 직접 탭
  - 터치 드래그/플릭
  - 필요 시 위/아래 화살표 버튼
  - 키보드/마우스 휠 의존 동작 없음

## 5. 통과 기준

- 뽑기 결과에서 신규/중복/초월/영웅석 전환을 즉시 이해할 수 있다.
- 3성 중복을 뽑아도 플레이어가 왜 보상인지 알 수 있다.
- 픽업 카드에서 5성/4성/무기 픽업이 명확히 구분된다.
- 10회 뽑기 확률이 조정되어 주요 캐릭터가 너무 빨리 소진되지 않는다.
- 전투 결과 화면은 경험치, 레벨, 다음 레벨 진행도를 중심으로 보인다.
- 전투 결과 하단 안내 문구가 별도 큰 블럭을 차지하지 않는다.
- 스테이지 선택 리스트의 기본 아이콘이 게임 스타일 아이콘으로 교체된다.
- 스테이지 선택 하단 텍스트가 모바일 화면과 배경 영역 안에 들어온다.
- 스테이지 선택은 터치/탭/드래그로 조작되고, 마우스 휠 동작에 의존하지 않는다.
