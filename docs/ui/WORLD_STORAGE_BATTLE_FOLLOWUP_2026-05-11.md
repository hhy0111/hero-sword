## 2. 마을 성 외곽 타일 구조 변경

### 현재 문제

- 성곽이 긴 이미지로 들어가 있어 화면의 전후좌우 구석에 정확히 맞지 않는다.
- 긴 성벽 이미지를 줄이거나 늘려 맞추는 방식은 구석/방향 전환/타일 경계에서 계속 문제가 생긴다.
- 성벽 높이 표현보다 위에서 내려다본 정사각형 타일 구조가 현재 마을 맵에 더 적합하다.

### 추가 작업 방향

- 성 외곽 이미지를 정사각형 타일 기반으로 교체한다.
- 필요한 신규 이미지:
  - 가로형 성벽 정사각형 타일 1개
  - 세로형 성벽 정사각형 타일 1개
- 각 타일은 위에서 내려다본 형태로 제작한다.
- 성벽 높이보다 타일 연결성, 모서리 맞춤, 반복 배치 안정성을 우선한다.
- 구석은 우선 가로/세로 타일의 겹침 또는 회전/미러링으로 처리한다.
- 전용 모서리 타일이 꼭 필요하다고 판단되면 별도 추가 프롬프트로 분리한다.

### 구현 메모

- 기존 긴 wall segment 스케일링 의존을 제거한다.
- 성 외곽은 타일 좌표 배열로 배치한다.
- 충돌 영역도 이미지 크기가 아니라 타일 좌표 기준으로 맞춘다.
- 같은 타일을 반복해도 너무 복사 붙여넣기처럼 보이지 않도록 미세 변형/오버레이가 가능한지 검토한다.

## 3. 창고 메뉴 추가

### 현재 문제

- 현재 장비함 화면은 장착 가능 장비를 고르는 팝업처럼 보인다.
- 사용자가 기대한 것은 장착하지 않고 보유 중인 모든 장비와 아이템을 보는 `창고` 메뉴다.
- 아이템을 눌렀을 때 상세 정보와 사용 가능 여부가 명확해야 한다.

### 추가 작업 방향

- 메인 메뉴에 `창고` 항목을 추가한다.
- 창고 화면에서 볼 수 있어야 하는 것:
  - 미장착 장비
  - 장착 중인 장비를 제외한 보유 장비
  - 소비 아이템
  - 재료/기타 아이템
- 탭 또는 필터:
  - 전체
  - 무기
  - 방어구
  - 소비
  - 재료
- 아이템을 누르면 상세 화면을 연다.
- 상세 화면에 표시할 정보:
  - 아이콘
  - 이름
  - 등급/종류
  - 보유 수량
  - 설명
  - 사용 가능 여부
- 소비 아이템의 경우에만 `사용하기` 버튼을 보여준다.
- 아무 효과가 없는 장비/재료/이벤트 아이템에는 `사용하기`를 보여주지 않는다.

### 소비 아이템 처리 규칙

- 사용 시 실제 능력치/재화/회복/버프에 영향이 있어야 한다.
- 사용 결과는 즉시 저장되어야 한다.
- 사용 후 수량이 감소해야 한다.
- 수량이 0이면 목록에서 숨기거나 0개 상태로 비활성 처리한다.
- 사용 불가 조건이 있으면 버튼 대신 이유를 표시한다.

예시:

- 회복 물약: 사용 가능, HP/회복 자원에 영향이 있을 때만 버튼 표시.
- 경험치 책: 사용 가능, 대상 캐릭터 선택이 필요하면 선택 UI 표시.
- 장비 강화 재료: 사용 버튼 없음, 강화 화면에서만 사용.
- 퀘스트 아이템: 사용 버튼 없음, 관련 퀘스트/설명만 표시.

## 4. 전투 화면 상단 패널 보완

### 현재 문제

- 전투 화면 상단에 기본 이미지처럼 보이는 영역이 남아 있다.
- 긴 스테이지명/목표/몬스터 체력 텍스트가 배경 테두리를 벗어날 수 있다.
- 상단 정보 패널과 버튼이 모바일 화면에서 안전 영역을 지키지 못한다.

### 추가 작업 방향

- 상단 패널을 실제 전투 UI용 이미지 또는 코드 프레임으로 정리한다.
- 추가 이미지가 필요한 경우 `docs/art/IMAGE_PROMPTS_ADDED_WORLD_STORAGE_BATTLE_FOLLOWUP_2026-05-11.md`의 전투 상단 패널 프롬프트를 사용한다.
- 텍스트 규칙:
  - 긴 스테이지명은 1줄 축약 또는 2줄 고정.
  - 목표/전투력/체력 텍스트는 패널 내부 폭 기준으로 줄바꿈.
  - 몬스터 체력바와 이름은 같은 패널 안에서 넘치지 않게 배치.
- 버튼 규칙:
  - 퇴각/메뉴/자동 등 버튼은 패널 경계 안에 들어오게 한다.
  - 버튼과 텍스트가 겹치면 버튼을 우선 오른쪽 별도 영역으로 고정한다.

## 5. 마을 복귀 위치 고정

### 현재 문제

- 월드맵에서 마을로 돌아올 때 시작 위치가 흐름과 맞지 않을 수 있다.
- 궁궐에서 나왔을 때도 항상 궁궐 앞에서 시작해야 동선이 명확하다.

### 추가 작업 방향

- 월드맵 -> 마을:
  - 항상 월드 출구/월드 게이트 앞 좌표에서 시작한다.
- 궁궐 -> 마을:
  - 항상 궁궐 입구 앞 좌표에서 시작한다.
- 타이틀/앱 재시작/기타 메뉴 복귀:
  - 기존 저장 위치나 마을 중앙 시작 정책과 충돌하지 않도록 별도 spawn reason을 둔다.

### 구현 메모

- 씬 전환 payload에 spawn reason을 명확히 전달한다.
  - `from_world_map`
  - `from_palace`
  - `default`
- `VillageLobbyScene` 진입 시 reason에 따라 시작 좌표를 고정한다.
- 자동 입장 반경 바로 위에서 시작해 재진입 루프가 생기지 않도록 약간 떨어진 좌표를 사용한다.
