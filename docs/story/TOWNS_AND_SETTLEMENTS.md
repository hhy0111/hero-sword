# TOWNS_AND_SETTLEMENTS.md

## 목적

마을은 단순 상점 메뉴가 아니라 플레이어가 돌아오는 감정적 기반이다. 다만 개발 범위가 폭주하지 않도록 `핵심 허브`, `지역 거점`, `전진캠프`로 나눈다.

## 거점 수 확정

- 핵심 허브: `1`
- 지역 거점 마을/도시: `6`
- 최종 전진캠프: `1`
- 총 메인 안전 거점: `8`

## 거점별 상세

| 거점 ID | 이름 | 규모 | 주요 기능 | 비고 |
| --- | --- | --- | --- | --- |
| `town_00` | 루멘 마을 | 대형 | 무기점, 방어구점, 아이템상점, 대장간, 길드 게시판, 하우징, 핵심 NPC | 시작 로비이자 메인 허브 |
| `town_01` | 브램블 마을 | 중형 | 농경 보급, 초반 장비, 평원 퀘스트 | 1대륙 거점 |
| `town_02` | 그란포지 | 중형 | 대장간 특화, 무기 개조, 재료 교환 | 2대륙 거점 |
| `town_03` | 블루하버 | 중형 | 항구 상점, 해안 유물, 거래소 NPC | 3대륙 거점 |
| `town_04` | 윈터가드 | 중형 | 방어 보급, 기사단 의뢰, 방한 장비 | 4대륙 거점 |
| `town_05` | 솔카자르 | 중형 | 유적 상인, 사막 보급, 희귀 재료 | 5대륙 거점 |
| `town_06` | 루미나 성도 | 대형 | 고급 상점, 성역 의회, 최종 스토리 NPC | 6대륙 거점 |
| `camp_01` | 검은문 전진캠프 | 소형 | 최종 정비, 파티 점검, 연합군 대화 | 종막 전용 |

## 루멘 마을 상세 구획

`루멘 마을`은 자유이동 마을의 기준이 되므로 구역을 미리 고정한다.

| 구역 | 용도 |
| --- | --- |
| 중앙 광장 | 메인 NPC, 이벤트, 공지 |
| 무기 거리 | 무기점, 대장간 |
| 방어구 골목 | 방어구점, 재봉 |
| 소모품 시장 | 아이템상점, 피로도 아이템 |
| 길드 회관 | 퀘스트, 파티 안내 |
| 주거 구역 | 하우징 진입 |
| 동문 | 월드맵 출구 |
| 서문 | 튜토리얼/초반 사냥터 연결 |

## 지역 거점 공통 규칙

- 큰 마을처럼 다 넣지 않는다.
- 지역 특화 기능 1개 + 공통 기능 3개만 둔다.
- 공통 기능:
  - 상인
  - 수리/강화 또는 대체 기능
  - 저장 포인트
  - 지역 대표 NPC

## 거점별 스토리 역할

| 이름 | 스토리 역할 |
| --- | --- |
| 루멘 마을 | 재앙의 시작과 귀환의 장소 |
| 브램블 마을 | 첫 민간 동맹 획득 |
| 그란포지 | 장비 복원과 맹약 재주조 |
| 블루하버 | 대륙 간 길 개방과 유물 회수 |
| 윈터가드 | 영웅단 기록 확보 |
| 솔카자르 | 봉인 진실 해독 |
| 루미나 성도 | 정치 갈등과 최종 선택 |
| 검은문 전진캠프 | 종막 집결지 |

## 출시 권장 구현 범위

### 1.0 필수

- 루멘 마을
- 브램블 마을
- 그란포지

### 1.0 축소 가능

- 블루하버 이후 거점은 `컴팩트 허브` 또는 `대화형 거점`으로 축소 가능

### 이후 확장

- 루미나 성도와 각 거점의 실내 건물
- 하우징 확장
- 거점별 미니게임 또는 생활 콘텐츠
