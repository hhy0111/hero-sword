# WORLD_STRUCTURE.md

## 전체 월드 구조 확정안

- 메인 월드 구성: `6개 대륙 + 1개 중앙 거점권 + 1개 최종 전진캠프`
- 메인 스토리 스테이지 수: `144`
- 난이도 구조: `Normal / Hard / Hell`
- 지역 해금 방식: `대륙 순차 해금`

## 맵 크기 정의

혼동 방지를 위해 `설정상 세계 규모`와 `개발용 맵 구성 규모`를 분리한다.

### 설정상 세계 규모

- 중앙 바다 `성흔해`를 둘러싼 6개 대륙 구조
- 대륙 간 이동은 항로, 협곡 관문, 성역 문, 균열 관문으로 설명
- 플레이어는 실제 월드 오픈월드를 뛰어다니는 것이 아니라 `대륙 지도형 진행`을 사용

### 개발용 맵 구성 규모

| 구분 | 규모 |
| --- | --- |
| 월드맵 UI 원본 기준 | `4096 x 4096` 단일 대형 맵 |
| 모바일 기준 표시 | `360 x 640`에서 스크롤/줌 |
| 대륙별 로컬 맵 카드 | `2048 x 1536` 기준 아트 |
| 루멘 마을 자유이동 구역 | 5 x 4 화면 구획 |
| 지역 거점 마을 구역 | 3 x 3 화면 구획 |
| 최종 전진캠프 | 2 x 2 화면 구획 |

## 마을 수 확정

### 메인 안전 거점 수

- 총 `8개`
- 구성:
  - 중앙 허브 1개
  - 대륙별 지역 거점 6개
  - 최종 전진캠프 1개

### 플레이 방식

- 모든 거점은 상점, NPC, 퀘스트 대화, 저장 포인트를 가진다.
- `루멘 마을`은 가장 큰 자유이동 허브로 고정한다.
- 나머지 거점은 지역 특화 서비스가 다르다.

## 왜 6대륙인가

- 144개 메인 스테이지로 대륙별 호흡과 현지 갈등을 충분히 쌓을 수 있다.
- 대륙당 테마, 적 세력, 보스, 주요 동료를 명확히 분리할 수 있다.
- 라이브 서비스에서 `대륙 단위 업데이트`가 쉽다.
- 3단 난이도와 조합했을 때 성장 루프가 길게 유지된다.

## 대륙별 역할

| 지역 | 스토리 역할 | 게임플레이 역할 |
| --- | --- | --- |
| 루멘 거점권 | 시작과 귀환의 장소 | 로비, 하우징, 핵심 상점 |
| 그린헤이븐 평원 | 첫 연합, 기본 세계관 소개 | 튜토리얼, 기초 성장 |
| 아이언리치 산맥 | 무기와 강화 체계 정착 | 장비/대장간 비중 강화 |
| 블루미스트 해안 | 이동로와 유물 회수 | 해안형 지형, 물/함선 연출 |
| 프로스트벨 고원 | 과거 진실 발견 | 방어전, 설원 지형, 군단전 |
| 선스카 사막 | 봉인의 진실, 제국 유적 | 함정, 고대 유적, 환영 연출 |
| 루미나 성역 | 정치 갈등과 최종 선택 | 성역 공성, 보스 연속전 |
| 검은문 전진캠프 | 최종 결전 직전 준비 | 제작, 파티 점검, 엔드게임 진입 |

## 월드맵 노드 규칙

- 각 대륙은 `거점 1개 + 스테이지 24개 + 부가 노드 2개` 구조로 보이게 만든다.
- 부가 노드는 아래 중 하나를 사용한다.
  - 보급 캠프
  - 균열 관측소
  - 서브 퀘스트 유적
- 메인 진행은 24개 스테이지 기준으로만 해금한다.
