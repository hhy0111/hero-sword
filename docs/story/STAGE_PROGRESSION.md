# STAGE_PROGRESSION.md

## 전체 진행 구조 확정안

- 메인 스토리 기준: `6개 대륙 x 24개 스테이지 = 144개`
- 각 스테이지는 `Normal / Hard / Hell` 3개 난이도를 가진다.
- 다음 대륙은 현재 대륙의 `24번 스테이지 Normal 클리어`로 해금한다.
- 같은 스테이지의 `Hard`는 `Normal 3성`, `Hell`은 `Hard 3성`으로 해금한다.
- 소탕은 해당 난이도 `3성 클리어` 후 열림.

## 24스테이지 대륙 템플릿

각 대륙은 `초기 진입 -> 거점 회복 -> 중반 진실 노출 -> 후반 봉인 돌입 -> 대륙 보스` 구조를 유지한다.

| 구간 | 스테이지 | 주 역할 |
| --- | --- | --- |
| 진입 구간 | `01~06` | 지역 소개, 보급로 회복, 주민 구조, 첫 동맹 형성 |
| 1차 분기 | `07~12` | 첫 중간보스, 추적전, 적 거점전, 지역 위기 수습 |
| 진실 구간 | `13~18` | 조각 반응 심화, 두 번째 중간보스, 기록/의식/핵심 정보 확보 |
| 최종 돌입 | `19~23` | 연합군 재집결, 봉인 회랑 진입, 보스 직전 위기전 |
| 대륙 결말 | `24` | 조각 회수, 동맹 확정, 다음 대륙 또는 최종 전선 개방 |

## 대화형 스토리 삽입 규칙

- 모든 스테이지에 대사를 붙이지 않는다.
- 대신 각 대륙마다 아래 6개 지점을 기본 스토리 이벤트로 사용한다.
  - `01` 입장 전
  - `06` 클리어 후
  - `13` 입장 전
  - `18` 클리어 후
  - `23` 입장 전
  - `24` 클리어 후
- 동료 합류 이벤트는 이 흐름과 별도로 `ResultScene` 하단 대화로 이어진다.
- 주요 영상 컷신은 `24`, 또는 특정 대륙의 `18/23` 지점에 배치한다.

## 대륙별 진행 요약

### 1대륙 `continent_01` 그린헤이븐 평원

- `01~06`: 브램블 진입, 수로/농로 복구, 초원 주민 구조
- `07~12`: 평원 선봉 붕괴, 제방 추적, 외성 붕괴 수습
- `13~18`: 봉인 언덕으로 전진, 흑월 선봉대 격파, 마지막 수문 복구
- `19~24`: 언덕 돌입, 제단 회랑, 모건 격파, 첫 조각 회수

### 2대륙 `continent_02` 아이언리치 산맥

- `01~06`: 광산 교통 복구, 통풍로와 광차선 회복
- `07~12`: 산맥 반란군 붕괴, 병영 습격, 쇳물 재난 수습
- `13~18`: 심부 승강로 추격, 바레스 격파, 반응로 안정화
- `19~24`: 산맥 심부 돌입, 맹약 주조, 드라보른 격파, 두 번째 조각 회수

### 3대륙 `continent_03` 블루미스트 해안

- `01~06`: 항만 봉쇄 해제, 해무 항로 확보, 부두 구조
- `07~12`: 약탈대 분쇄, 성소 외전 정리, 가라앉는 등대 구조
- `13~18`: 성소 안쪽 의식 추적, 엘렌트 격파, 성소 붕괴 속 기록 회수
- `19~24`: 조수문 심부 진입, 네레프 격파, 세 번째 조각 회수

### 4대륙 `continent_04` 프로스트벨 고원

- `01~06`: 윈터가드 진입, 수송과 외곽 방어선 복구
- `07~12`: 설원 장교 제거, 묘역 접근, 빙원 붕괴 생존전
- `13~18`: 영웅단 기록 확보, 흐로드 격파, 봉인자 기록 회수
- `19~24`: 봉인탑 돌입, 발테른 격파, 네 번째 조각 회수

### 5대륙 `continent_05` 선스카 사막

- `01~06`: 교역로와 오아시스 확보, 초반 사막 약탈군 진압
- `07~12`: 협곡 추적, 유적 외곽 정리, 태양신전 붕괴 탈출
- `13~18`: 봉인 기록 해독, 세트라 격파, 모래폭풍 속 기록 회수
- `19~24`: 심판길과 봉인회랑 돌입, 카제르 격파, 다섯 번째 조각 회수

### 6대륙 `continent_06` 루미나 성역

- `01~06`: 성도 진입, 시민 탈출, 성역 외곽 회복
- `07~12`: 징벌관 제거, 기사단 전초 붕괴, 종각 탈환
- `13~18`: 성역 심판로 추적, 세르딘 격파, 검은 의식 제단 붕괴
- `19~24`: 검은문 진입, 연합군 최종 집결, 바르칸 격파, 엔딩

## 동료 합류 기준선

- 각 대륙당 핵심 합류는 `초반 1`, `중반 1`, `후반 1` 구조를 유지한다.
- 후반 합류자는 다음 대륙이나 최종 전선의 설명자 역할까지 겸한다.
- 실제 런타임 매핑은 `src/game/data/stageRecruitEvents.ts`를 기준으로 유지한다.
