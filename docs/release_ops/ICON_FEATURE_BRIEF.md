# ICON_FEATURE_BRIEF.md

## 목적

- 앱 아이콘과 피처 그래픽 제작 전에 브리프를 먼저 고정한다.
- 실제 제작물은 아직 없지만, 아트/마케팅/스토어 설명이 같은 방향을 보게 만든다.

## 앱 아이콘 브리프

- 핵심 모티프: `검`, `금이 간 봉인 조각`, `붉은 달 흔적`
- 우선 인상: `정통 판타지 ARPG`, `과도한 모바일 캐주얼 아님`, `선명한 실루엣`
- 색 방향:
  - 금속: `낡은 금빛 + 은회색`
  - 포인트: `붉은 균열광`
  - 배경: `짙은 청록 또는 흑청`
- 금지:
  - 얼굴 클로즈업 남발
  - 과한 광택
  - 기존 유명 RPG 로고와 유사한 십자/문양

## 피처 그래픽 브리프

- 권장 구성: `카인 전신 + 복원 중인 히어로소드 + 붉은 달 균열 + 멀리 보이는 2대륙 지형 암시`
- 메시지: `마을 -> 탐험 -> 전투 -> 조각 회수`
- 필요 텍스트:
  - 기본안: 텍스트 없는 버전
  - 보조안: `히어로소드` 로고 포함 버전
- 프레임 구성:
  - 좌측: 주인공 실루엣
  - 중앙: 검/균열 포인트
  - 우측: 월드맵 또는 대륙 실루엣

## 제출 기준

- 앱 아이콘: 정사각형 원본 1종 + 투명 배경 보관본
- 피처 그래픽: `1024 x 500` 기준 원본 1종
- 실제 인게임 복장/무기와 불일치 금지
