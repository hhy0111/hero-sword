# STORE_IMAGE_PRIORITY.md

## 목적

- Google Play 제출용 이미지를 `필수 먼저`, `설명 강화용 나중` 순서로 분리한다.
- 아트팀이 시간 부족 상황에서도 최소 제출 세트를 우선 확보하게 만든다.

## 우선순위 규칙

- `P0`: 없으면 스토어 준비가 바로 막히는 핵심 세트
- `P1`: 장르 이해와 전환율에 직접 도움 되는 확장 세트
- `P2`: 출시 직전 또는 운영 단계에서 보강 가능한 세트

## P0 필수 먼저

| 우선순위 | 자산 | 이유 | 사용 프롬프트 |
| --- | --- | --- | --- |
| P0-1 | 앱 아이콘 | 브랜드 인지와 등록 기본값 | `STORE_READY_TO_COPY_PROMPTS.md` 1번 |
| P0-2 | 피처 그래픽 | 스토어 상단 핵심 비주얼 | `STORE_READY_TO_COPY_PROMPTS.md` 2번 |
| P0-3 | 스크린샷 1 로비 마을 | 허브 구조, 상점, 조작 방식 설명 | `STORE_READY_TO_COPY_PROMPTS.md` 4번 |
| P0-4 | 스크린샷 5 일반 전투 | 핵심 장르 전달 | `STORE_READY_TO_COPY_PROMPTS.md` 8번 |
| P0-5 | 스크린샷 6 보스전 | 전투 스케일 전달 | `STORE_READY_TO_COPY_PROMPTS.md` 9번 |
| P0-6 | 스크린샷 2 월드맵 | 장기 진행 구조 전달 | `STORE_READY_TO_COPY_PROMPTS.md` 5번 |

P0 완료 기준:
- 아이콘, 피처 그래픽, 핵심 스크린샷 4종이 같은 브랜드 톤으로 묶인다.
- 스크린샷만 봐도 `마을`, `탐험`, `전투`, `보스전` 흐름이 읽힌다.

## 최소 제출 세트 권장 조합

시간이 부족하면 아래 순서만 먼저 만든다.
1. 앱 아이콘
2. 피처 그래픽
3. 로비 마을
4. 일반 전투
5. 보스전
6. 월드맵

## 제작 전 체크

- 아이콘용 주인공 얼굴/검 모티프가 이미 승인되었는가
- 스크린샷용 UI가 실제 게임 구조와 충돌하지 않는가
- 광고/IAP 화면은 실제 운영 정책과 어긋나지 않는가
- 스토어 컷이 인게임 자산과 다른 복장이나 다른 무기를 쓰지 않는가
