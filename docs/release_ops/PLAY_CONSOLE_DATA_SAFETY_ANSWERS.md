# PLAY_CONSOLE_DATA_SAFETY_ANSWERS.md

## 목적

Google Play Console `데이터 보안` 입력값을 히어로소드의 현재 SDK 구성에 맞춰 고정한다.
현재 앱은 자체 계정 서버를 운영하지 않지만, `AdMob`, `Google Play Billing`, `RevenueCat` 사용으로 인해 일부 사용자 데이터 수집/공유를 공개해야 한다.

## 기준일

- 작성일: `2026-05-18`
- 앱: `히어로소드 (Hero Sword)`
- 패키지명: `com.appstudioon.herosword`
- 개인정보처리방침: `https://hhy0111.github.io/hero-sword/privacy-policy.html`

| --- | --- |
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | `예` |
| 앱에서 수집하는 모든 사용자 데이터를 암호화하여 전송하나요? | `예` |
| 계정 생성 방법 | `앱에서 사용자가 계정을 만들도록 허용하지 않음` |

## 데이터 유형 선택

체크할 항목:

- 위치: `대략적인 위치`
- 금융 정보: `구매 내역`
- 앱 활동: `앱 상호작용`
- 앱 정보 및 성능: `진단`
- 기기 또는 기타 ID: `기기 또는 기타 ID`

체크하지 않을 항목:

- `정확한 위치`
- `개인 정보`
- `건강 및 피트니스`
- `메시지`
- `사진 및 동영상`
- `오디오 파일`
- `파일 및 문서`
- `캘린더`
- `연락처`
- `웹 탐색`

## 입력하지 않는 자체 수집 항목

히어로소드 자체 코드 기준으로 아래 기능은 현재 없다.

- 자체 회원가입/로그인
- 이름, 전화번호, 주소 수집
- 정확한 GPS 위치 권한
- 연락처, 사진, 마이크, 캘린더 접근
- 채팅, 사용자 생성 콘텐츠 공유
- 자체 서버 분석 이벤트 수집

로컬 저장 데이터는 기기 안에 저장되며, 현재 별도 자체 서버로 전송하지 않는다.

## 유지보수 규칙

- 광고 SDK, 결제 SDK, 분석 SDK를 추가하거나 변경하면 이 문서를 다시 검토한다.
- `src/config/runtime.ts`의 광고/IAP 설정이 바뀌면 `RELEASE_INPUTS.md`와 이 문서를 함께 갱신한다.
- Play Console 실제 입력 후에도 콘솔 답변과 이 문서가 다르면 문서를 즉시 맞춘다.
