## 짧은 설명 초안

- `마을을 복구하고 여섯 대륙의 조각을 모아 히어로소드를 되살리는 정통 판타지 ARPG`

## 긴 설명 초안

`히어로소드`는 검게 물든 달의 재앙으로 봉인검이 산산이 부서진 뒤 시작되는 모바일 판타지 ARPG입니다.  
루멘 마을을 거점으로 삼아 대륙을 탐험하고, 4인 파티를 편성해 전투를 돌파하며, 각 지역의 동맹과 함께 검의 조각을 되찾아야 합니다.

### 핵심 특징

- 자유 이동 가능한 마을 허브와 월드맵 기반 대륙 진행
- 4인 파티 자동전투 + 수동 스킬 개입
- `Normal / Hard / Hell` 3단 난이도와 3성 해금 구조
- 장비, 가챠, 하우징으로 이어지는 메타 루프
- 오프라인 플레이와 로컬 저장 지원

### 1.0 출시 범위

- 프롤로그
- 1대륙 `그린헤이븐 평원`
- 2대륙 `아이언리치 산맥`
- 3대륙 예고

### 플레이 흐름

루멘 마을에서 파티를 정비하고, 월드맵에서 다음 대륙을 선택한 뒤, 스테이지를 돌파해 보상과 장비를 모으세요.  
광고 보상과 상점, 하우징 같은 보조 루프도 진행을 돕지만, 핵심은 전투와 성장, 그리고 동맹을 모아가는 모험에 있습니다.
