# EQUIPMENT_RULES.md

## 목적

- 무기군과 방어구군의 관계를 한 문서에서 고정한다.
- 장비 종류, 성급, 강화가 서로 다른 축이라는 점을 명확히 한다.
- 기획, UI, 밸런스, QA가 같은 장비 언어를 사용하게 만든다.

## 장비 구조 확정

- 직업마다 `장착 가능한 무기군`이 정해진다.
- 직업마다 `장착 가능한 방어구군`이 정해진다.
- 장착 가능 여부는 런타임에서 `보유 캐릭터 + 장비 사본 + 무기군/방어구군 일치 + 캐릭터 레벨`을 모두 만족해야 한다.
- 무기군과 방어구군은 `장비 카테고리`이지, 장비 1개를 뜻하지 않는다.
- 같은 무기군 안에는 여러 개의 개별 무기가 존재한다.
- 같은 방어구군 안에는 여러 개의 개별 방어구가 존재한다.
- 장비의 `종류`, `성급`, `강화`, `초월/한계돌파`는 서로 다른 성장 축이다.

## 성장 축 정의

| 축 | 의미 | 현재 상태 |
| --- | --- | --- |
| 장비 종류 | 실제 아이템 이름과 기본 옵션 | 확정 |
| 무기군/방어구군 | 직업 장착 제한 카테고리 | 확정 |
| 성급 | `3성/4성/5성` 희귀도 축 | 계수표 확정 |
| 강화 | 골드/재료 기반 수치 상승 | `+1 ~ +15` 구간표 확정 |
| 초월/한계돌파 | 중복 또는 전용 재화 기반 추가 성장 | 구조 확정, 수치 후속 |
| 전용 패시브 | 전용무기/고급 장비의 고유 효과 | 규칙 확정 |

## 상점 장비 공급 규칙

- 상점 장비는 `source: shop`으로 분리하고, 소환/스테이지 보상 장비와 같은 인벤토리 사본 구조를 사용한다.
- 초반 상점 장비는 즉시 구매 가능하게 두고, 중반 이후 장비는 특정 스테이지 노멀 클리어 후 목록에 노출한다.
- 상점 장비는 현재 보유 캐릭터 중 같은 장비군을 쓰는 캐릭터의 현재 장착 상태와 비교해 `전투력 +/-`를 표시한다.
- 레벨이 부족한 장비도 구매는 가능하지만, 상점 상세와 장착 화면에서는 필요한 레벨을 표시하고 실제 장착은 막는다.
- `무기 상점`은 검, 방패검, 활, 랜스, 대검, 권총, 단검, 기사검을 중심으로 공급한다.
- `방어구 상점`은 판금, 중갑, 경갑, 성직복, 기동복, 로브를 중심으로 공급한다.
- `대장간`은 망치, 룬해머, 캐논, 룬 작업복처럼 제작/정비 성격의 장비를 공급한다.
- `유물 상점`은 마도서, 지팡이, 기록서, 유물봉, 시미터, 성검, 성가봉, 고급 로브/경갑을 공급한다.
- `아이템 상점`은 현재 피로도 회복형 소모품만 즉시 적용형으로 판매한다. 별도 보유형 소비 아이템 인벤토리는 후속 범위다.

## 현재 확정 결정

- 무기/방어구는 `종류`, `성급`, `강화`, `초월`을 독립 축으로 유지한다.
- `1.0`에서는 장비 이해를 단순화하기 위해 세트 효과를 도입하지 않는다.
- 장신구는 구조만 선고정하고 코드 활성화는 `1.1 이후`에 수행한다.
