# MONSTER_ROSTER_EXPANSION_2026-05-02.md

## 목적

- 기존 대륙별 적 풀은 보스 포함 약 `30종` 수준이었다.
- 이번 확장에서는 대륙별 `10종`, 전체 `60종`으로 늘려 스테이지 수 확대와 함께 전투 인상이 반복되지 않도록 한다.
- 실제 런타임 기준 카탈로그는 `src/game/data/monsters.ts`를 따른다.

## 운영 원칙

- 새 몬스터는 `이름/역할/설명`을 먼저 늘리고, 아트가 들어오기 전까지는 `기존 runtime enemy subject`를 placeholder로 재사용한다.
- 대륙당 최소 포함군:
  - 슬라임 1
  - 코볼트 계열 1
  - 근접 전열 1
  - 원거리 1
  - 돌진형 1
  - 시전형 1
  - 중간 보스 1
  - 최종 보스 1

- 테마: 성역 붕괴, 흑월 침식, 성가 왜곡

## 런타임 연결 방식

- 전투 시 `stage.stageType`만 보지 않고 `대륙별 몬스터 풀`을 읽어 이름과 runtime subject를 가져온다.
- 초중후반 스테이지는 같은 패턴이라도 다른 이름과 설명을 쓰도록 분기한다.
- 보스가 아닌 적도 `frontier / mid / late` 단계에 따라 이름이 바뀌어 체감 다양성을 만든다.
