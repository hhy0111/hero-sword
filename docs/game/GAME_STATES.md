# GAME_STATES.md

## 상위 상태

| 상태 | 설명 | 진입 조건 | 이탈 조건 |
| --- | --- | --- | --- |
| Boot | 초기 로드 | 앱 실행 | 저장 로드 완료 |
| VillageLobby | 마을 허브 | 저장 로드 완료 | 지도/상점/집/전투 준비 진입 |
| WorldMap | 대륙 선택 | 로비에서 지도 진입 | 대륙 확정 또는 뒤로가기 |
| StageSelect | 스테이지 선택 | 대륙 선택 | 입장/소탕/뒤로가기 |
| PartyPrep | 파티 확인 | 스테이지 선택 | 시작/취소 |
| Battle | 전투 | 파티 준비 완료 | 승리/실패/이탈 |
| Result | 결과 | 전투 종료 | 로비 복귀/재도전 |
| Modal | 광고/IAP/튜토리얼 등 | 상위 상태 유지 중 팝업 호출 | 확인/취소/완료 |

## 경계 조건

- 광고 팝업은 `Battle` 중 직접 열리지 않는다.
- 저장 실패 시 현재 상태를 유지하고 재시도 안내를 띄운다.
- 튜토리얼 중단 후 재진입 시 마지막 완료 단계 기준으로 복원한다. [TODO]
