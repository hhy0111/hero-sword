# ACCESSORY_RULES.md

## 목적

- 장신구 슬롯을 당장 코드에 활성화하지 않더라도 구조와 용어를 먼저 고정한다.
- 장비 문서와 UI 문서가 이후 확장 시 다른 이름을 쓰지 않게 만든다.

## 현재 결정

- 장신구는 `1슬롯` 구조로 먼저 고정한다.
- `1.0`에서는 런타임 비활성 상태를 유지하고, `1.1 이후` 활성화를 목표로 한다.
- 이유:
  - 2대륙 컷에서는 무기/갑옷만으로도 메타 루프 설명이 가능하다.
  - 장신구를 함께 열면 인벤토리 복잡도와 밸런싱 축이 과도하게 늘어난다.

## 장신구 분류

| 분류 | 역할 | 대표 능력치 |
| --- | --- | --- |
| 반지 | 공격/정밀 | 치명타율, 적중, 관통력 |
| 부적 | 생존/저항 | 최대HP, 상태이상저항, 회피율 |
| 문장 | 파티 지원 | 버프효율, 치유력, 스킬가속 |

## 희귀도 규칙

| 희귀도 | 슬롯 성격 | 사용 의도 |
| --- | --- | --- |
| 3성 | 단일 보조 스탯 | 초반 메타 루프 학습용 |
| 4성 | 2개 스탯 조합 | 역할 보정용 |
| 5성 | 핵심 스탯 + 조건부 효과 | 빌드 방향성 제공 |

## 획득처

- 히어로스톤 상점
- 이벤트 임무
- 하우징 교환 보상
- 대륙 평판 상점

## UI 원칙

- 장신구 슬롯이 비활성일 때는 `추후 개방` 문구만 노출한다.
- 활성화 시에도 자동 장착 추천을 먼저 제공한다.
- 세트 효과는 장신구 활성화 이후에도 즉시 넣지 않는다.
