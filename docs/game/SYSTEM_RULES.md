## 2026-05-17 Fatigue and Replay Reward Rules

- 최대 피로도: `100`
- 스테이지 입장 소모: `3`
- 자연 회복: `5분당 1`
- 보상 광고 회복: `+6`
- 광고 실패 fallback 회복: `+3`
- 결제 피로도 팩: 소형 `+18`, 대형 `+45`
- 이미 1성 이상 클리어한 같은 스테이지/난이도는 반복 클리어 시 골드와 EXP를 `50%`만 지급한다.
- 기존 저장 데이터의 `1000` 기준 피로도는 로드 시 비율을 유지해 `100` 기준으로 변환한다.

## 피로도

- 최대치: `1000`
- 회복: `5분당 1`
- 스테이지 입장 소모: `10`
- 회복 수단:
  - 자연 회복
  - 이벤트/퀘스트 보상
  - 보상형 광고
  - 상점 구매

## 장비/무기

- MVP 기준 장비는 `주무기 1슬롯`부터 시작한다.
- MVP 기준 방어구는 `갑옷 1슬롯`부터 시작한다.
- 장착 조건은 `직업 제한 + 레벨 제한`으로 관리한다.
- 무기군과 방어구군은 카테고리이고, 그 안에 여러 개의 개별 장비가 존재한다.
- 장비 종류와 `성급`, `강화`, `초월`은 별도 성장 축으로 관리한다.
- 상점, 스테이지 보상, 이벤트, 히어로스톤 상점에서 기본 장비를 공급한다.
- 전용무기 가챠는 별도 운영하되 기본 무기군과 직업 제한은 유지한다.
- 장비 구조 총괄은 `./EQUIPMENT_RULES.md`, 무기 상세는 `./WEAPON_RULES.md`, 방어구 상세는 `./ARMOR_RULES.md`를 기준 문서로 사용한다.
