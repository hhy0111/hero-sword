# IMAGE_REVIEW_PLAYBOOK.md

## 목적

- 생성 결과를 빠르게 `PASS`, `SOFT FAIL`, `FAIL`로 분류한다.
- 수정 요청 문장을 짧고 일관되게 유지한다.
- `asset_agent`, `qa_agent`, `integration_agent`가 같은 기준으로 검수하게 만든다.

## 검수 흐름

1. 요청한 프롬프트 파일명과 항목 번호를 기록한다.
2. 생성 결과를 30초 안에 `즉시 반려 여부`부터 확인한다.
3. 즉시 반려가 아니면 구조/비율/실루엣을 본다.
4. 구조가 통과하면 스타일 일관성, 상용 자연스러움, AI 티를 본다.
5. 게임 화면에 넣었을 때 읽히는지 상상 기준이 아니라 실제 사용 위치 기준으로 판정한다.
6. `PASS`, `SOFT FAIL`, `FAIL` 중 하나로 잠근다.
7. `SOFT FAIL` 또는 `FAIL`이면 수정 요청을 3개 이내로 줄여 다시 요청한다.

## 1차 즉시 반려 기준

- 손가락 수, 무기 결합, 관절 방향이 비정상적이다.
- 얼굴이나 장비가 프롬프트 대상과 다른 캐릭터처럼 보인다.
- 무기가 바뀌거나 좌우 뒤집힘으로 구조가 달라진다.
- 복장 층이 장면마다 달라져 애니메이션 분해가 어렵다.
- 생성형 티가 강하게 난다.
- UI 컷에서 숫자, 버튼, 탭 계층이 읽히지 않는다.
- 스토어 이미지가 인게임 톤과 다른 광고용 일러스트처럼 뜬다.

## 자산군별 중점 항목

### 플레이어블 캐릭터

- 파티에 세웠을 때 직업이 즉시 구분되는가
- 애니메이션 분해 가능한 관절 정보가 보이는가
- 무기 크기가 캐릭터마다 과장 없이 일관적인가
- 승리/피격/다운 상태에서 같은 인물로 유지되는가

### NPC

- 직업과 역할이 실루엣만으로 읽히는가
- 상점 NPC끼리 같은 마을 톤을 공유하는가
- 대화 초상과 전신이 다른 인물처럼 보이지 않는가

### 적/보스

- 공격 방식이 형태만 보고 추론 가능한가
- 모바일 화면에서 일반 적, 엘리트, 보스 위계가 분명한가
- 과한 가시, 과한 광택, 과한 붉은 빛으로 퉁치지 않았는가

### 장비/아이콘

- 작은 크기에서 읽히는가
- 아이콘 가족끼리 광원, 외곽선, 재질 표현이 같은가
- 전투 UI에 얹었을 때 배경과 섞이지 않는가

### 배경/환경

- 이동 가능 공간과 장식 공간이 구분되는가
- 건물 구조가 말이 되는가
- 마을, 필드, 보스전 배경이 같은 프로젝트 톤인가

### 스토어 이미지

- 실플레이 감이 보이는가
- 과한 광고 문구 없이도 게임 장르가 읽히는가
- 아이콘, 피처 그래픽, 스크린샷이 한 브랜드처럼 묶이는가

## 판정 기준

| 판정 | 의미 | 후속 조치 |
| --- | --- | --- |
| `PASS` | 바로 적용 가능 | 버전 기록 후 반입 후보 등록 |
| `SOFT FAIL` | 방향은 맞지만 수정 필요 | 수정 요청 1회 후 재검수 |
| `FAIL` | 방향 자체가 어긋남 | 프롬프트 수정 후 재생성 |

## 수정 요청 작성 규칙

- 수정 요청은 최대 3개만 남긴다.
- `고칠 것`과 `유지할 것`을 함께 적는다.
- 추상어 대신 구조어를 쓴다.

좋은 예시:
- `현재 실루엣과 색 배치는 유지하고, 오른손 검 길이만 15% 줄여 주세요.`
- `얼굴은 유지하고, 갑옷 어깨 장식을 줄여서 애니메이션 분해가 가능하게 해 주세요.`
- `UI 계층은 유지하고, 버튼 텍스트 영역 대비만 높여 주세요.`

나쁜 예시:
- `더 멋있게 해 주세요.`
- `좀 덜 AI 같게 해 주세요.`
- `자연스럽게 고쳐 주세요.`

## 검수 기록 템플릿

| 항목 | 내용 |
| --- | --- |
| 자산 ID | 예: `chr_kain_animation_design_v001` |
| 자산군 | 캐릭터 / NPC / 적 / 배경 / 장비 / VFX / 스토어 |
| 사용 프롬프트 | 파일명 + 항목 번호 |
| 검수 라운드 | `R1`, `R2`, `R3` |
| 판정 | `PASS` / `SOFT FAIL` / `FAIL` |
| 핵심 이슈 | 3개 이내 |
| 수정 요청 | 복붙 가능한 문장 |
| 검수자 | 이름 또는 역할 |
| 검수일 | YYYY-MM-DD |
