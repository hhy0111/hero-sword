# VFX_DIRECTION.md

## 목적

- 스킬 이펙트, 피격, 보상 연출 프롬프트를 만들기 위한 기준을 먼저 잠근다.
- 화려함보다 모바일 가독성과 상용 게임다운 통일성을 우선한다.

## VFX 공통 방향

- 작은 휴대폰 화면에서도 읽혀야 한다.
- 캐릭터 실루엣을 가리지 않아야 한다.
- 과도한 bloom, 입자 남발, 뿌연 연막을 금지한다.
- 속성별 색 구분은 하되, 장난감처럼 원색만 과하게 쓰지 않는다.

## 프롬프트 제작 시 강제 규칙

- 반드시 `배경 투명`, `캐릭터 실루엣 가리지 않음`, `모바일 가독성 우선`을 명시한다.
- 반드시 `과한 광원 번짐 금지`, `입자 과밀 금지`를 넣는다.
- 같은 속성이라도 공격, 회복, 버프, 피격 이펙트를 구분한다.
