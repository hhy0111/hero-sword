# ART_QA_CHECKLIST.md

## 판정 규칙

- `PASS`: 바로 사용 가능
- `SOFT FAIL`: 수정 후 재검토 필요
- `FAIL`: 방향 재작업 필요

## 사용 순서

1. 먼저 `IMAGE_REVIEW_PLAYBOOK.md` 기준으로 즉시 반려 여부를 본다.
2. 즉시 반려가 아니면 아래 체크리스트를 채운다.
3. `SOFT FAIL` 또는 `FAIL`이면 수정 요청을 3개 이내로 줄인다.
4. `PASS` 전까지는 `assets/` 반입 금지다.

## 체크리스트

| 항목 | 기준 | 판정 |
| --- | --- | --- |
| 구조/비율 | 비정상적인 관절, 무기 결합, 건물 비율 왜곡이 없는가 | 미실행 |
| 대칭 | 인체와 장식이 기계적으로 좌우대칭이지 않은가 | 미실행 |
| 재질 | 광택과 표면이 과도하게 매끈하지 않은가 | 미실행 |
| 장식 | 의미 없는 장식이 떠 있지 않은가 | 미실행 |
| 디테일 밀도 | 화면마다 밀도가 들쭉날쭉하지 않은가 | 미실행 |
| 톤 일치 | UI와 아트가 서로 다른 게임처럼 보이지 않는가 | 미실행 |
| 상용 자연스러움 | 실제 상용 게임 문맥에서 자연스러운가 | 미실행 |
| 생성형 티 | 이상한 연결부, 어색한 형태가 없는가 | 미실행 |
| 버튼/아이콘/배경 일관성 | 서로 다른 프로젝트 산출물처럼 보이지 않는가 | 미실행 |
| 인간 마감 품질 | 사람이 다듬은 결과물처럼 보이는가 | 미실행 |
