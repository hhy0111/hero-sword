# STORE_READY_TO_COPY_PROMPTS.md

아래 프롬프트는 `공통 프롬프트 없이` 그대로 복사해서 바로 요청할 수 있는 형태로 작성했다.

사용 규칙:
- Google Play용 마케팅 이미지를 기준으로 쓴다.
- 스크린샷 프롬프트는 `게임 화면 자체`에 집중하고, 과한 광고 문구 합성은 피한다.
- 필요 시 후반 편집에서 텍스트를 추가할 수 있게 `텍스트 없는 고품질 배경/연출 컷`을 우선한다.
