# ENEMY_VISUAL_SCOPE.md

## 목적

- 전체 이미지 프롬프트를 만들 수 있도록 적/보스 범위를 대륙별로 먼저 잠근다.
- 일반 몬스터, 엘리트, 보스를 섞지 않고 역할별로 나눠 프롬프트를 만든다.

## 적 프롬프트 구성 원칙

- 대륙마다 `일반 적 3종 + 보스 2종` 기준으로 잡는다.
- 일반 적은 `근접`, `원거리/특수`, `엘리트/중장` 축을 우선한다.
- 보스는 [STAGE_PROGRESSION.md](../story/STAGE_PROGRESSION.md)의 명칭을 따른다.
- 너무 많은 잡몹 변형보다 `대륙 테마가 읽히는 적 계열`을 우선한다.

## 총 프롬프트 범위

- 일반 적 프롬프트: `18개`
- 중간 보스 프롬프트: `6개`
- 대륙 보스 프롬프트: `6개`
- 총 적/보스 프롬프트 목표 수: `30개`

## 비주얼 공통 기준

- 일반 적은 한눈에 역할이 읽혀야 한다.
- 대륙 보스는 `실루엣`, `공격 방식`, `지역 테마`가 동시에 보여야 한다.
- 보스는 과도한 뿔, 가시, 광택에 기대지 말고 `전투 패턴이 읽히는 형태`를 우선한다.
- 생성형 이미지 특유의 무의미한 파츠 증식은 금지한다.
