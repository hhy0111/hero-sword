# ENEMY_READY_TO_COPY_PROMPTS.md

아래 프롬프트는 `공통 프롬프트 없이` 그대로 복사해서 바로 요청할 수 있는 형태로 작성했다.

사용 규칙:
- 일반 적은 `투명 배경 스프라이트/시트용 디자인` 기준으로 요청한다.
- 중간 보스와 대륙 보스는 `보스 패키지 시트 또는 키비주얼용 디자인` 기준으로 요청한다.
- 한 번에 `적 1종`만 요청한다.
