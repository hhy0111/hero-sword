# CHARACTER PACKAGE SHEETS

이 폴더는 `docs/art/CHARACTER_READY_TO_COPY_PROMPTS.md` 기반으로 생성한
`애니메이션 제작용 캐릭터 패키지 시트` 원본을 보관한다.

주의:
- 이 파일들은 게임이 직접 읽는 최종 스프라이트 시트가 아니다.
- 현재 용도는 `캐릭터 턴어라운드`, `키포즈`, `액션 설계` 참고용 source asset이다.
- 실제 런타임 반영 전에는 도트 프레임 분리, 투명 배경 정리, atlas 편입 작업이 필요하다.

폴더 규칙:
- `approved/`: 캐릭터 패키지 시트로 사용 가능한 레퍼런스
- `review-needed/`: 프롬프트 오출력, 캐릭터 불일치, 재생성 필요 자산

현재 상태:
- `approved/`: 20장
- `review-needed/`: 1장
- `pending prompts`: 1건

확인 메모:
- `19-seraphine-1.png` 원본은 `Thorn Wolf`로 생성되어 캐릭터 패키지 시트가 아니므로
  `review-needed/19-seraphine-wrong-output-thorn-wolf-v1.png`로 이동했다.
- `20-michaela-1.png` 원본은 실제 내용이 `Seraphine`이라
  `approved/19-seraphine-package-sheet-v1.png`로 정리했다.
- `21-lucian-1.png` 원본은 실제 내용이 `Michaela`라
  `approved/20-michaela-package-sheet-v1.png`로 정리했다.
- 따라서 현재 `Lucian` 전용 패키지 시트는 누락 상태이며 재생성이 필요하다.
